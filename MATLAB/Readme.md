### Required MATLAB Toolboxes

To run the parameter initialization and control design scripts (`LQR_design.m`, `PID_design.m`, etc.), ensure the following toolboxes are installed:

* **MATLAB Core System**
* **Control System Toolbox:** Required for state-space modeling (`ss`), dynamic system analysis (`ctrb`, `obsv`, `step`), and optimal control gain calculation (`lqr`).
* **Symbolic Math Toolbox:** *(Optional)* Used for deriving symbolic equations of motion and linearizing non-linear system dynamics.
